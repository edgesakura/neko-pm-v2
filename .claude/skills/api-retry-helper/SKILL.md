# API Retry Helper

外部API呼び出しのための汎用リトライロジック実装パターン集。

## 適用場面

- 外部API連携（Anthropic, OpenAI, AWS等）
- HTTP/REST APIクライアント実装
- レート制限のあるサービス連携
- マイクロサービス間通信
- データベース接続エラー対応

## 核心パターン

1. **Exponential Backoff**: リトライ間隔を指数的に増加（1s→2s→4s→8s）
2. **レート制限対応**: HTTP 429 は待機時間2倍
3. **最大リトライ回数**: 3-5回（無限ループ防止）
4. **Jitter**: ランダム偏差で衝突防止
5. **サーキットブレーカー**: 連続失敗でリクエスト停止
